% Festival discount Default % off for Keyboard, Accessories and Mouse catalog products Settings

Applies to Keyboard, Accessories & Mouse catalog products only — completely separate from Deskmat's own maintenance-mode discount (Deskmat Admin ↗). Every product gets this default % off while the switch is on, unless it has its own override set in the Discount % column on the Products tab (leave a product's override blank to use the default, or set it to 0 to exclude that product from the sale).

Start/end are optional. If set, the sale is only actually live while the switch above is ON and the current time is inside this window — leave the switch on and it'll turn itself off when the window ends. Leave both blank to control it with the switch alone.
